94:Two built-in CXF interceptors correlate a request across client and server logs. `ExchangeIdDecorator` (incoming, `Phase.RECEIVE`) assigns a UUID to the CXF exchange (key `exchangeId`) and publishes it in the SLF4J MDC as `RequestExchangeId`. `ExchangeIdResponseWriter` (outgoing, `Phase.POST_LOGICAL`) echoes it as the `X-Exchange-Id` response header, and only when `ExchangeIdDecorator` has set an id on the exchange; its fault handler delegates to the normal handler, so error responses carry the header as well.
